About

I’m a data scientist who cares most about simplicity and optimisation: finding the cleanest, most efficient path from a messy problem to an answer people can trust.

Day to day, I shape ideas into features for platforms that handle high-volume financial data, working in R, Python and SQL, from forecasting to machine learning. I also design the prompts that guide AI agents through pipeline work. Outside work, I learn by building: my latest project is InkDoc, an open-source app that converts documents into clean Markdown for LLM and RAG pipelines. One rule runs through all of it: if it can’t be reconciled, it isn’t done.
